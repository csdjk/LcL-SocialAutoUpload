# 投稿状态确认

任务中心与今日待发布的人工确认窗口仅保留状态选择。根据平台看到的结果选择“审核中”“已公开发布”“需本人处理”“仍不确定”或“确认没有作品”，再点击“确认状态”。不再填写作品 ID、链接或核对依据，也不需要另外勾选确认项。

## 自动保留任务信息

保存时由后端读取原任务的账号、作品 ID 和链接，生成确认时间和“用户手动确认状态”说明，来源标为 `manual_confirmation`。没有作品链接时保持为空，不生成链接或作品 ID。人工确认与“从平台回读”各自保留来源；确认按钮只更新记录，不上传、不重投。

原任务已经有作品 ID 或链接时，不能直接标记“确认没有作品”来清除它；先从平台回读核对。没有作品信息的任务允许用户直接确认审核或公开状态，不要求补填参数。

## 错误与并发

窗口固定原任务和记录版本。保存期间按钮禁用；任务已更新时返回 409，窗口显示具体错误并提示重新打开。排队或执行中的任务仍不能人工覆盖；已公开发布的记录不能回退。旧的详细核对 API 与 CLI 仍保留其原有校验。

## 本轮验证

临时数据库覆盖无参数确认、保留已有作品信息、原记录版本冲突、非法确认标记及不触发投稿。后端 51 项及 3 项子测试、前端 11 项测试和构建通过。页面验收在本机 Edge headless、隔离 API 下检查两个入口的默认弹窗、选择状态、保存错误和成功关闭；不更改真实投稿状态。截图与结果保存在 `Temp/status-confirmation-qa/`。
