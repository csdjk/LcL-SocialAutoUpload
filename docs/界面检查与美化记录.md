# 界面检查与美化记录

日期：2026-09-27。范围：现有五个主入口、内容库与设置子页，以及受影响的弹窗。沿用柔和立体风格与现有导航结构。

## 发现的问题与修改

| 实际问题 | 修改 |
| --- | --- |
| 输入框、卡片和按钮阴影偏重；深色提示框与页面不协调 | 减轻外阴影与内阴影，统一边框、控件尺寸、文字配色和提示框底色 |
| 各页面标题字号不一致；折叠菜单图标偏右 | 统一标题层级，补齐页面说明；侧栏改为可键盘操作的按钮，折叠后图标居中 |
| 任务详情重复展示状态、完整时间戳、账号与作品 ID | 新增全部/待处理/处理中/已发布筛选；显示北京时间；账号、作品与核对记录折叠；已公开任务不再重复显示完整进度条 |
| 五个平台的三列编辑区过窄，视频预览占用较多首屏空间 | 平台卡片改为两列并在窄屏单列；预览缩小并增加封面；增加视频标题和简短资源信息 |
| 账号头像颜色随机，账号页视觉层级与其他页面不同 | 改为本地文字头像，取消第三方头像请求；统一标题、列表、按钮与表头 |
| 排程复选框受页面通用 label 样式影响发生错位 | 将网格规则限定到时间字段；修正复选框文字和说明对齐 |
| 小屏输入焦点框被弹窗滚动区域裁切 | 焦点描边改为向内绘制，保留清晰键盘焦点 |
| 手机素材页搜索框与操作按钮挤在一行；上传弹窗宽度只有视口 40% | 搜索与操作分行；上传/预览弹窗采用自适应宽度；上传区文字分成两行 |
| 进入素材页自动弹“刷新成功”；关于页仍显示旧平台列表 | 初次加载安静完成，手动刷新保留提示；关于页更新为当前五平台和实际能力说明 |

没有修改发布状态判定、投稿通道、真实账号或自动排程配置。

## 验证

- `npm --prefix sau_frontend run build`：通过。
- `node --test tests/*.test.js`：79 项通过。新增检查覆盖状态分组、北京时间跨日显示、来源标签。
- 修改前与修改后分别保存 20 张真实本机服务截图：相同页面、视口和 DPR 人工前后检查。
- 隔离 API 页面验收：96 张截图，8 次状态确认请求全部被测试接口截获；0 页面脚本错误、0 检测到的横向页面溢出。没有执行真实投稿。
- 焦点、素材页、关于页和上传弹窗使用真实本机服务补查，修正后重新截图。页面打开和弹窗取消没有保存状态、上传文件或修改账号。
- 视口：1440×960、320×568、375×667、390×844；DPR 1；浅色和深色。手机视口启用移动模式，主交互检查启用减少动态效果。
- 环境：Windows、本机 Edge headless；真实服务 `http://127.0.0.1:5409/`；隔离页面 `http://127.0.0.1:5424/`。
- 方法：运行截图人工检查间距、层级、换行、裁切、弹窗排列；DOM 检查页面溢出、弹窗安全边距与筛选结果。不是参考图复刻，没有像素相似度目标。
- 修正后的 64px 折叠侧栏，五个图标中心均为 x=32px，深浅色一致。输入焦点描边 2px、偏移 -2px，在四个视口和两种主题下验证。
- 配色计算：正文/次要文字相对卡片底色的对比度，浅色为 13.32/5.63，深色为 12.70/7.60。此数值覆盖这些文字配色，不等同于完整无障碍认证。
