# 抖音账号登录

账号管理 → 添加账号或重新登录 → 平台选「抖音」，默认使用「浏览器登录」。也可选择「导入登录态」。

新增账号无需填写名称，验证后自动读取抖音昵称；昵称读取失败时不会保存空名称账号。重新登录保留原账号名称。

## 浏览器登录并记住账号

点击「打开 Edge 登录」，在普通 Edge 窗口完成平台登录，工具验证并保存后关闭窗口。该窗口使用账号独立的持久化浏览器资料，后续通过同一账号的「重新登录」继续使用原资料；不会每次创建无痕会话。

无需安装或使用浏览器扩展。工具资料与平时使用的 Edge 资料相互独立，因此首次需在工具窗口登录；平台会话过期或要求安全验证时，仍需本人完成。已有账号和发布凭据不因移除扩展功能而删除。

## 从 Edge 直接粘贴 Cookie

账号管理 → 添加账号 → 抖音 → 导入登录态 → 粘贴 Cookie。不需要安装扩展或手工制作 JSON。

在你平时使用的 Edge 里正常登录抖音创作者中心（creator.douyin.com），打开后台后按 F12，选择「网络 / Network」并刷新页面。在筛选栏输入 `domain:creator.douyin.com`，选中一个带 Cookie 的请求，进入「标头 / Headers → 请求标头 / Request Headers」。右键 Cookie 对应的值，选择「复制值 / Copy value」。

回到本机工具，将完整 Cookie 粘贴到输入框，点击「验证并添加账号」。输入框使用密码式遮挡；切换输入方式或关闭弹窗后清空。不复制 Authorization、Set-Cookie、整段 cURL，也不将内容粘贴到聊天里。使用完可复制一段普通文字替换剪贴板内容。

Edge 操作依据：Microsoft Learn《网络功能参考》https://learn.microsoft.com/zh-cn/microsoft-edge/devtools/network/reference

## 导入已有登录态文件

选择「JSON 文件」，选择不超过 512 KB 的 JSON 文件，再点击「验证并添加账号」。支持本工具保存的 Playwright storage_state JSON，以及只包含 Cookie 对象的导出数组。文件必须来自你自己的抖音账号，并且会话仍然有效。

已有抖音账号可使用该行的「上传Cookie」进入同一个验证导入流程。验证失败不会覆盖原账号，成功后才切换到新凭据。不同平台的凭据不会被写入抖音账号。

网页登录态与抖音开放平台 access_token 不是同一种凭据。不能把单个 access_token 改名为 JSON 后导入；OAuth 接口需要对应应用权限和用户授权，现有 Web 发布器使用的是浏览器登录态。

## 没有登录态文件

选择「浏览器登录」，点击「打开 Edge 登录」。在弹出的工具专用 Edge 中，按抖音官方页面提示完成登录及必要的身份验证。此模式不提取二维码，也不修改官方验证页面。页面跳转使旧扫码回执无法读取时，窗口会继续等待，不会因此立即关闭。

成功的判断需要已登录页面的实际控件和会话凭据；仅有页面跳转或手机确认消息不算登录成功。账号保存前关闭窗口会取消本次添加。

## 2046 与验证失败

2046 表示本次官方扫码回执要求额外安全验证，需要按官方提示在 App 或网页完成。导入已有 Cookie 不是绕过安全验证，过期、不完整或被平台拒绝的登录态不会被当作正常账号添加。

## 隐私与保存

导入接口仅接受本机页面的显式请求；请求体和凭据内容不进入应用日志，响应不回传凭据。文件归一化后仅保留抖音域名的 Cookie 和浏览器存储数据，并保存在已被 Git 忽略的 cookiesFile 目录。临时验证失败会清理本次临时文件。

登录态可能被用来操作你的账号。请勿上传到聊天、群或代码仓库；只在本机工具里选择文件。

## 本次验证范围

回归测试覆盖格式兼容、凭据保密、域名限制、无效 Token、有效性验证失败、并发新增/删除、失败不覆盖旧账号及官方窗口回执误判。真实账号能否导入成功仍以本人有效文件和抖音实际验证结果为准；本次修改不包含上传或发布视频。

完整使用说明见 [浏览器登录与自动保存](浏览器登录与自动保存.md)。
