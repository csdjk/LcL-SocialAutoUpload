## 投稿实现

实现位于 `publishing/xiaohongshu_browser.py`，使用账号管理保存的登录态和小红书创作网页。

1. 先读取原账号完整默认笔记列表，按同日同标题查重。分页未完整、登录失效或多条匹配时停止。
2. 上传视频，填写文案；逐项选择真实话题，核对话题关联结果；按素材声明选择「笔记含AI合成内容」。
3. 填写文案后再打开封面悬停菜单，防止上传完成时自动滚动使菜单消失。新版封面编辑器明确选中已上传图片，裁剪选择 3:4 后保存。
4. 保存后核对预览比例、图片内容并截图；错误或仍是视频帧时停止，不静默降级。
5. 发布按钮位于官方闭合 Shadow DOM，通过 CDP 读取真实按钮文字、启用状态和可见坐标，再发送一次正常鼠标点击。提交后不重复点击。
6. 回查官方笔记 ID 与状态。`tab_status=2` 实测对应审核中；`tab_status=1` 且 `permission_code=0` 对应已发布。保存原始状态字段；未确认时继续保留防重复保护。队列会同步小红书已有任务结果，此操作不创建新投稿。
