# 小红书登录昵称读取修复

## 原因与修复

2026-09-27 使用本次失败登录留下的工具专用 Edge 配置复现：官方创作后台已登录，账号为「发现好游」，登录检测返回 `valid`；当前昵称元素为 `.user-info .name-box`，旧规则未覆盖，导致账号保存前报「未读取到平台账号昵称」。

在 `utils/account_identity.py` 的小红书规则加入该限定选择器。仍要求对应平台 HTTPS 页面、可见且唯一的有效昵称。没有使用页面标题、笔记名或默认名称代替账号名。

## 实际验证

- 修复前真实页面复现读取失败；修复后复用原工具专用浏览器配置，通过现有登录验证和保存流程恢复账号，无需再次扫码。
- 账号管理保存「发现好游」，小红书平台，状态「正常」。
- `tests/test_account_auto_name.py`、`tests/test_browser_auto_login.py`：79 项通过。新增用例覆盖当前昵称元素、无关笔记名、隐藏昵称和多个冲突昵称。
- 网页服务与桌面服务已重启。使用 Windows / headless Edge / 1320×880 实际打开 `http://127.0.0.1:5409/#/account-management` 和 `http://127.0.0.1:5410/#/account-management`，均验证账号行状态正常。
