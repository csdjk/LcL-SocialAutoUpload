# 视频号封面弹窗修复

适用错误：4:3 横版封面设置失败，`编辑封面` 的第一个匹配弹窗为 hidden。

## 修改范围

只修改 `uploader/tencent_uploader/main.py` 中 `TencentVideo` 的封面方法。登录、账号选择、视频上传、发表方法与投稿账本不变。

- 从唯一、可见的封面组件打开编辑器；优先点击组件内明确的编辑按钮。不再使用整页 `div:has-text(...)` 作为后备入口。
- 对弹窗要求可见、标题匹配且包含文件输入。隐藏的缓存弹窗不参与选择；多个可见匹配时停止，避免操作错误窗口。
- 文件输入本身可以隐藏，但其编辑弹窗必须可见。相同文件再次选择前清空旧选择，确保组件收到 change 事件。
- 出现裁剪框时先完成裁剪。等待新预览稳定、无忙碌状态、确认按钮可用，再确认主编辑器，并等待主编辑器关闭。
- 必需封面失败仍停止投稿；错误只显示简洁原因，不把整段浏览器 Call log 填进发布卡片。

## 本机回归

```powershell
.\.venv\Scripts\python.exe -X utf8 -m pytest tests/test_tencent_cover_dialog.py -q
```

此测试直接调用工程内 `TencentVideo`。使用 Playwright 与生产代码所用的 Patchright 分别驱动独立 Edge，对内存 HTML 测试隐藏同名弹窗、延迟打开、横竖两种图片、裁剪、预览未更新、重复文件、确认后不关闭等情况；另验证封面失败时不会调用发表方法。测试拦截所有 HTTP/HTTPS 请求，不使用 Cookie、用户日常浏览器或任何真实投稿。

## 验证边界

离线回归不等于视频号官网成功投稿。网站布局后续变动仍可能需要适配。此次修改不上传文件到官网，不修改既有任务状态，不自动重试，不跳过平台验证或强行删除遮罩。

重启后端后使用新代码。旧任务若仍为“结果待核对”，先在对应账号内容管理及草稿箱核对，再使用工具现有的“记录核对结果”操作；不要把仅完成视频上传或封面编辑当作公开发表成功。
