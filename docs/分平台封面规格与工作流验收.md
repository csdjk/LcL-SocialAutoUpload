# 分平台封面规格与工作流验收

核对日期：2026-09-27。适用于后续新交付；没有修改今天已经发布的作品或原正式包。

## 输出规格

| 平台 | 工作流输出 | 依据与边界 |
| --- | --- | --- |
| B站 | 1200×900，4:3 | 沿用现有成功投稿的兼容尺寸，不宣称为官方最低要求 |
| 抖音 | 横版 1440×1080；竖版 1080×1440 | 对应现有上传器的两个封面槽位 |
| 视频号 | 横版 1440×1080；竖版 1080×1440 | 分别绑定独立图片，禁止用视频帧代替失败的自定义封面 |
| YouTube | 3840×2160，16:9 | 官方当前普通视频缩略图推荐尺寸；不用于 Shorts |
| 今日头条 | 1920×1080，16:9 | 工作流输出目标，避免沿用旧 4:3 图后临时补边 |
| 快手 | 1080×1440，3:4 | 工作流输出目标，仍待真实投稿和回查验收 |

YouTube 来源：[缩略图说明](https://support.google.com/youtube/answer/72431?hl=en)、[thumbnails.set API](https://developers.google.com/youtube/v3/docs/thumbnails/set)。当前 API 最大上传量为 50 MB；生成器统一采用 2 MiB 的本地压缩预算，不能把该预算写成官方 API 上限。

国内平台公开资料未能确认全部封面硬性像素下限。已只读检查 B站、抖音、今日头条、快手的创作后台入口；页面中的视频清晰度要求不作为封面要求。视频号入口本轮重定向到首页。表中相应尺寸均明确为工具输出目标，不能替代平台真实上传验收。未配置的小红书未纳入本轮自动生成和发布范围。

## 工作流变更

1. 视频技能的 `assets/cover-profiles.json` 统一管理 8 张封面的尺寸、预算、平台和依据。
2. 可共用同一新闻主视觉，但各尺寸独立排版、独立文件；保留原图完整内容，取消固定焦点裁切。过宽的原图在竖图中主体过小时，人工更换适合竖版的来源素材。
3. 先生成八图预览和联系表，检查原尺寸与小缩略图中的标题、主体、比例和留白；尺寸合格不等于视觉验收合格。
4. 正式交付复制已经审核的预览字节，并验证 SHA-256；规格或模板指纹变化会使旧预览失效。
5. 新包记录尺寸、格式、字节预算及规格版本。发布工具入队前核实平台映射、真实图片尺寸、比例、JPEG 格式和预算。历史无版本包沿用既有校验。
6. 页面从素材真实元数据生成比例、横竖名称和分辨率，支持点击放大。YouTube 与头条不再被标成 4:3。
7. 已更新原每日 06:00 视频自动化提示词，保留原排程和发布授权。生成平台素材不会自动开启新平台投稿。
