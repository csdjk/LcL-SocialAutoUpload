# YouTube 与今日头条

## 使用入口

1. 在“账号管理 → 添加账号”选择平台，无需填写名称。YouTube 按 [官方授权配置](YouTube官方授权配置.md) 导入桌面 OAuth JSON，点击「Google 授权」，由系统默认浏览器确认频道。今日头条点击「打开 Edge 登录」，在工具持久化窗口完成登录。
2. 在“今日待发布”的对应平台卡片中选择该账号。普通视频也使用这里绑定的发布账号。
3. 展开平台文案，核对标题、简介、封面和声明。YouTube 需选择可见性与儿童受众；普通视频不会替用户预选儿童受众。头条标题上限 30 字，超出会阻止入队，不自动截断。
4. 选择平台投稿，或在内容库预约投稿时间。在任务中心查看执行进度与回执。

## 当前支持范围

- 账号类型：YouTube 为 6，今日头条为 7；发布平台键为 `youtube`、`toutiao`。
- YouTube 使用 Google OAuth 和官方 Data API v3；头条使用创作者网页浏览器通道。
- 复用统一队列、账号锁、草稿、任务账本与 MCP。旧三平台资源包以视图补充新平台文案，保留原文件与校验摘要。
- 头条封面须检测到更新后的图片预览才继续。YouTube 在取得视频 ID 后调用官方封面接口；失败保留视频并提示补设封面，不会丢失回执或重新上传。
- 最终提交只尝试一次；上传完成必须有平台页面的明确提示。提交后无可靠回执时记为“结果待核对”，不自动重新投稿。
- YouTube 回执来自官方 API；自动回读处理状态及实际可见性，私享或不公开不会标为公开。头条先读取结果窗口，再从原账号官方内容列表回查同日同标题的唯一作品；预览链接不代表公开发布。
- 自动排程入口已支持两平台，迁移旧配置时默认关闭。原来的日报三平台自动发布配置保持原值。
