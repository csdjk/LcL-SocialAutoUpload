# 快手登录昵称读取修复

## 原因与改动

2026-09-27 在原失败登录的工具专用浏览器配置中复现：快手登录检测为 `valid`，右上角账号昵称为 `L`，但 `read_account_name(4, page)` 报「未读取到平台账号昵称」。当前官方页面使用 `.user-info-name`，原读取规则未覆盖该元素。

`utils/account_identity.py` 的快手规则加入该精确类名。仍要求原平台 HTTPS 页面、可见元素、唯一且有效的昵称，不使用视频标题或临时默认名称。
